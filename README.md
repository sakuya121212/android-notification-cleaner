# NotificationCleaner

Androidの通知を選択したアプリごとにまとめ、後から確認・削除できるアプリです。ログはアプリごとの見出しで表示されます。

## 対応 Android バージョン

Android 8.0（API レベル 26）以降

通知アクセスと通知の送信を許可したうえで、設定画面から自動クリーンの対象アプリを選択してください。対象アプリから届いた通知は通知バーから整理され、このアプリ内でアプリ別に確認・個別削除・一括削除できます。まとめ通知のチャンネルをオフにした場合は、元の通知を消去しません。

通知をクリーンすると、元通知の「返信」などのアクションボタンは引き継がれません。メッセージアプリは必要に応じて個別に有効化してください。
